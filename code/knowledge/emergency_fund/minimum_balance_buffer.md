# The Minimum Balance Buffer as an Emergency Reserve

The `minimum_balance_to_keep` represents a non-negotiable financial floor. It protects the individual from account insolvency in the event of minor cash shocks or delayed paychecks.

### Hard Invariant Rule
Under no circumstances may any payment plan, down payment, installment, or simulated essential expenditure cause the projected daily bank balance to drop below this minimum balance floor. Any proposal that violates this floor at any point during the 90-day forecast is mathematically deemed unsafe and rejected.
