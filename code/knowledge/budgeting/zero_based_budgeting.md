# Zero-Based Cash Allocation

Zero-based budgeting assigns every unit of incoming cash a specific purpose before expenditure occurs:
- Immediate Essential Reserves: Funds locked to cover known scheduled debits (rent, utilities, loan repayments).
- Variable Essential Allowance: Buffer allocated for necessary variable expenses like food and transit.
- Untouchable Safety Floor: The individual user's minimum balance threshold.
- Unallocated Surplus: The only pool truly available for new discretionary purchases.

### Application to Large Expenses
Before sanctioning any new financial commitment, the system verifies that upcoming scheduled debits and variable essential expenses are fully covered. When unallocated surplus is insufficient to absorb the full requested expense immediately, the purchase is not affordable today without compromising scheduled obligations.
