# Principles of 90-Day Cash Flow Forecasting

Static balance checks are dangerous because a positive bank account today can turn into an overdraft tomorrow when pending or scheduled debits hit.

### Key Forecasting Rules
1. Multi-Day Simulation: Model daily account balance trajectories across at least a 90-day forward-looking horizon.
2. Conservative Timing: Confirmed salaries and recurring credits should only be credited on their verified settlement dates.
3. Pending Debit Deduction: All pending authorizations, card holds, and in-flight transfers must be treated as already deducted.
4. Trajectory Headroom: The lowest balance trough across the entire forecast window defines the true maximum safe expenditure headroom, not today's raw account balance.
